# Part 1: Search

**2 parts, 6 marks**

## Context

**The Grid**

A robot moves on a \(4 \times 4\) grid from the top-left cell to the
bottom-right cell. Each move goes up, down, left or right and costs 1.

## Questions

**1A. [1 mark]** Which search algorithm finds a shortest route?

a. Depth-first search  
b. Breadth-first search  
c. Greedy best-first search

**1B. [2 marks]** Which of these heuristics are admissible? Select all that apply.

a. The Manhattan distance to the goal  
b. The straight-line distance to the goal  
c. Twice the Manhattan distance to the goal  
d. None of the above

**1C. [2 marks]** A shortest route makes (1) ______ moves and visits (2) ______ cells.

**1D. [1 mark]** What is the Manhattan distance from the start to the goal?
